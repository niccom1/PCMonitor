一个完全由AI编写的性能监视器。

在Releases页面下载可执行的二进制文件到本地运行后打开浏览器输入 127.0.0.1:8081 就即可打开WebUi。
<img width="931" height="672" alt="a332de5b00d6e4adb507a613dc71e96e" src="https://github.com/user-attachments/assets/e8e29423-7c30-4ea8-88b6-ea0f00ae759b" />

在 config.json 内可以自定义端口(1~65535)。
<img width="481" height="90" alt="image" src="https://github.com/user-attachments/assets/5c78e8b5-3a28-4010-8069-c1d158d5854f" />

支持同局域网内其他设备访问，你只需要 Win+R 输入 cmd 打开控制台后输入 ipconfig 获得本机 IPv4地址。

<img width="399" height="230" alt="image" src="https://github.com/user-attachments/assets/55368567-e046-46ff-89b1-cebdb0932737" />
<img width="431" height="395" alt="image" src="https://github.com/user-attachments/assets/2a96dde6-1109-4ecd-b8b6-30104ff871c3" />


然后在其他设备上输入你获取到的IPv4地址和你的端口号即可打开WebUi.
